# LRC 智能歌词编辑器

一款功能完整的 LRC 歌词图形化编辑器：支持**音乐播放打轴**、**批量时间戳操作**、**智能修复**、**文件夹播放列表**、**四套皮肤**，并提供高 DPI 支持。

> **开发说明：本项目由 [ZCode](https://zcode.z.ai/)（AI 编程助手）辅助开发完成**


## 运行

**方式一：直接使用 exe（推荐）**

到 [Releases](../../releases) 下载 `LRCEditor.exe`，双击即用，无需安装 Python。
（也可自行打包，见下文）

**方式二：源码运行**

```bash
pip install pygame        # 唯一的第三方依赖
python lrc_editor.py
```

## 功能特性

### 歌词编辑
- **行内直接编辑**：双击歌词/时间戳单元格就地修改（回车确认、Esc 取消），不开弹窗
- **行首 + 按钮**：点击在该行下方插入空行；悬停可一次插入 1/2/3/5/10 行
- **行首 ☑ 复选框 = 多选**：勾选即加入选中（与 Ctrl+点击等同），配合删除/平移/复制等批量操作
- **剪贴板**：Ctrl+C 复制 / Ctrl+X 剪切多行、Ctrl+V 粘贴到选中行下方（时间戳留空等待手动打轴；粘贴外部 LRC 文本则保留其时间戳）
- **按住句子上下拖动**：直接连续多选（无需等待）
- 多选批量操作（**Ctrl+A** 全选）、查找替换（支持正则）
- 调整时间戳**不实时重排**：打轴/微调时行保持原位，所见即所编；播放歌词照常显示
- 保存时如有未打轴（无时间戳）的句子或**时间戳乱序**会弹窗提醒（仍按当前顺序保存，可用『⇅ 排序』整理）
- 元数据标签（标题/歌手/专辑/制作/偏移）可视化编辑
- **Ctrl+Z 撤销 / Ctrl+Y 重做**：所有改动可撤销（最多 60 步）
- 一键**智能修复**（F9）：剥离逐字标签 → 清理空行/无效行 → 去重 → 排序 → 标准化
- 兼容解析非标格式：`[mm:ss]`、`[mm:ss.xxx]`、一行多时间戳、增强型逐字 LRC 自动转逐行

### 时间戳
- 整体/选中行批量平移（支持小数秒）
- 主页快速平移按钮：±0.25s / ±0.5s / ±1s，无需弹窗
- 时间戳格式标准化（毫秒 2/3 位）

### 音乐播放打轴
- 加载 mp3 / wav / ogg / flac / m4a，**空格**播放暂停、**回车**打轴
- **回车目标四种模式**（进度条旁可切换）：
  - **手动打轴（选中行）**：给选中的行打轴并自动跳下一行；不按旧时间戳自动换行，从零创建或大改时不会串句
  - **跟随时间戳（当前句）**：暂停在句中，回车把"正在唱的这句"对齐到暂停点
  - **跟随时间戳（下一句）**：听到歌词切换的瞬间按回车，对齐下一句，绝不会落到上一句
  - **手动打轴且自动平移后面句**：该句对齐后，后面每一句按相同差值自动平移（逐句链式对轴）
  - 打轴按钮旁实时显示"◎ 将打轴：第 N 句"
- **列顺序可拖动**：按住列头拖动可调换列位置（如把 ☑ 列拖到 + 后面）
- **行内 − 按钮**：点击直接删除该行（Ctrl+Z 可撤销）
- **选中句微调**：Alt+←/→ ±100ms、Shift+Alt+←/→ ±10ms；播放中微调会立即跳到新起点试听
- 每行行尾 ▶ 按键：点击直接从该句播放
- 播放时当前句"呼吸"高亮、自动滚动跟随（手动滚动后暂停 2 秒；换行检测 60ms）
- **打轴校准**（±2000ms）：补偿固定偏差，全程生效并记忆
- **设为首句开头**：暂停后右键任意句 → 该句对齐当前时间点，后续句同步平移

### 时长跳转
- 进度条拖动实时预览目标时间戳与歌词，当前秒数就显示在进度条旁，松手跳转
- Ctrl+G 跳到指定时长；Ctrl+J / 行尾 ▶ 跳到选中句；±2s 微调（Ctrl+←/→）

### 文件夹播放列表
- 打开文件夹自动扫描音频，⏮/⏭ 上一首下一首（Ctrl+PgUp/PgDn，循环）
- 切换前**确认保存**（是/否/取消）；每首歌自动加载同名 LRC
- 打开音频自动找同名 LRC，打开 LRC 自动找同名音频；没有 LRC 显示占位指引

### 界面
- **高 DPI 原生渲染**：150%/200% 缩放下清晰不发虚
- 四套皮肤 + 深色标题栏 + 淡入淡出/呼吸/脉冲动画
- 实时 LRC 预览；异常行高亮（红=无时间戳，黄=重复时间戳/空行）
- 多编码保存（UTF-8/GBK 等，自动识别）

## 打包 exe

```bash
pip install pyinstaller
python -m PyInstaller --noconfirm --onefile --windowed --name LRCEditor lrc_editor.py
```

产物在 `dist/LRCEditor.exe`（约 30MB，内置 pygame 解码器）。

## 项目结构

```
lrc_editor.py        主程序（单文件，约 1300 行）
sample.lrc           示例歌词
tests/               自动化功能测试（python tests/test_playlist.py）
tools/bench_seek.py  跳转精度基准测试（ffmpeg 可选，用于生成 mp3/ogg 测试音频）
启动编辑器.bat       Windows 双击启动
```

## 时间精度说明

- 播放位置基于系统单调时钟手动跟踪，暂停/恢复/跳转连续性误差 < 1ms
- 跳转端到端实测误差 ±10~20ms（wav/mp3 CBR/mp3 VBR/ogg 均实测，见 `tools/bench_seek.py`）
- 固定偏差可用"打轴校准"补偿；人耳反应时间（约 150~250ms）为打轴误差大头
